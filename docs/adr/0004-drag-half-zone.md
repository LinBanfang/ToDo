# ADR-004: 拖放半区插入约定

## 状态
已采纳

## 背景
任务拖拽排序固定插到目标项之前，拖到"两项之间"需精确对准目标上半，不符合直觉。

## 决策
统一采用**半区插入**：拖到目标行上半 → 插到目标前；拖到下半 → 插到目标后。应用于任务行、步骤行、侧边栏列表、待办项分组、侧边栏列表分组。所有拖起要求位移超过 `SystemParameters.Minimum{Horizontal,Vertical}DragDistance`，并用上/下指示线（accent）跟随指针。拖放结束用 `_suppressTaskClick` 标志（非时间窗）抑制误触发的行选中。

## 后果
- 优点：跨所有可排序对象一致、可发现（指示线）。
- 权衡：跨区域（不同分组/列表）的列表拖放不重排也不移动（无操作）；系统列表固定顺序不可拖。
- 需在分组/列表重命名状态禁用拖放（否则拖动会抢焦点打断重命名）。
